## Consistency Analysis

### pyproject.toml Files ✓ CONSISTENT

**Strengths**:
- All use Python 3.11+
- All have nats-py, pydantic, aiosqlite
- Identical dev dependencies (pytest, black, ruff, mypy)
- Identical tool configurations
- Consistent package naming: `activelearning-{service}`

**Service-Specific Dependencies** (Correct):
- kernel, planner, safety-supervisor: Don't need aiohttp or qdrant-client (verified)
- beliefs: networkx for graph operations
- meta-programmer: docker, agno for code generation
- coordinator: numpy for data processing
- external-api: anthropic, openai for API access
- overrides: opencv-python, pyaudio for multimedia

### Dockerfiles ✓ MOSTLY CONSISTENT

**Consistent Patterns**:
- All use `python:3.11-slim`
- All install gcc with proper cleanup
- All use `/app` as WORKDIR (except sandbox: `/sandbox`)
- All set `PYTHONPATH`
- All have proper CMD entries

**Known Variations** (Intentional):
- sdk: Uses pyproject.toml with editable install, has scripts/ directory
- meta-programmer: Installs Docker CLI for spawning sandboxes
- overrides: Installs OpenCV + PortAudio for camera/mic support
- sandbox: Runs as non-root user (security hardening for test environment)

**Opportunity for Improvement**:
- Most services use requirements.txt (redundant with pyproject.toml)
- Only sandbox runs as non-root user (security consideration)
